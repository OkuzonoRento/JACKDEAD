# スロットの音の差し替え方

`Assets/Resources/SlotSounds` フォルダに、下の名前で音声ファイル（wav / mp3 / ogg）を置くと、コードで作った音の代わりに使います。
置いた分だけ差し替わります。名前は大文字・小文字まで合わせてください（拡張子は何でもかまいません）。

**使ってよい音だけを入れてください。** 実在の機種（ジャグラーなど）の音や曲は、録音したものでもメーカーの著作物です。
配布・公開するゲームに入れるには許可が必要です。素材サイトの音は、利用規約（ゲームへの利用、表記の要否）を確認してください。

| ファイル名 | 鳴る場面 | 長さの目安 | 備考 |
|---|---|---|---|
| `Start` | ボタンを押した | 0.9 秒以内 | 0.85 秒後にリールが回り出す |
| `Lever` | リールが回り出す | 0.3 秒 | |
| `SpinLoop` | 回っている間 | 0.4 秒〜 | 繰り返す。つなぎ目のない音にする |
| `ReelStop` | リールが 1 本止まる | 0.25 秒 | |
| `Blip` | そろった目を左から数える・倍率が出る | 0.2 秒 | 高さを変えて鳴らす |
| `Tick` | 金額の数え上げ | 0.08 秒 | 高さを変えながら繰り返し鳴らす |
| `Slam` | 大当たりが出る瞬間の一撃 | 0.5〜1 秒 | BIG WIN と JACKPOT |
| `Payout` | 払い出し | 1.2 秒 | すべての当たり |
| `BigWin` | BIG WIN の曲 | 2.5 秒 | |
| `Jackpot` | JACKPOT の曲 | 4.5 秒 | |
| `Coin` | メダルが床で跳ねる | 0.2 秒 | 高さを変えて何度も鳴る |
| `Reroll` | 再ロール | 0.7 秒 | |
| `Lose` | ハズレ | 0.5 秒 | |

演出の時間は音の長さに合わせて変わりません。長い曲は、次に回したときや攻撃を受けたときに途中で止まります。
音量は `SlotMachineController` の `celebration` → `Sound Volume` と、設定画面の SE 音量です。
